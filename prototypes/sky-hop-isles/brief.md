## Look and references
- Look: 밝은 로우폴리 3D에 부드러운 그림자. 하늘색에서 연한 복숭앗빛으로 넘어가는 그라데이션 하늘, 섬 윗면은 풀빛 초록, 옆면은 따뜻한 갈색 흙과 바위. 주인공은 빨간 망토의 작은 캐릭터로 위험한 대상과 바로 구별되고, 적과 위험물은 보라와 주황으로 칠한다. 대표 디테일은 발밑에 항상 생기는 둥근 그림자로, 착지 지점을 읽게 해 준다. 모든 형체는 그려서 만들고 이모지나 맨 원은 쓰지 않는다. *(provisional)* 빛: 낮은 해가 옆에서 비추는 노을녘, 길고 부드러운 그림자, 따뜻한 대기 안개, 틈새의 앰비언트 오클루전, 해·랜턴·황금 별에 블룸, 뉴트럴 톤 매핑.
- References: Neon White(선명한 로우폴리), Super Mario 3D World(섬 단위 코스와 발밑 그림자) *(guessed)*
- View: 3D · Camera: 캐릭터 뒤 위쪽 orbit 카메라. 진행 방향을 미리 보여 주고 평범한 점프에는 흔들리지 않는다. *(provisional)*

## First minute
넓고 평평한 첫 섬에서 시작한다. 걷다가 작은 틈을 만나면 Space로 건너고, 높은 턱 앞에서는 길게 눌러야 오를 수 있다는 걸 직접 해 보며 배운다. 이어서 체크포인트 깃발을 지나는데, 떨어지면 바로 그 깃발에서 다시 시작한다. 이 1분은 천천히 움직이는 발판을 타고 큰 틈을 건너는 첫 짜릿한 점프로 끝난다. *(guessed)*

## Challenge
1분 무렵 움직이는 발판, 순찰하는 적, 사라지는 발판이 겹치며 첫 고비가 온다. 떨어지거나 맞으면 마지막 체크포인트로 즉시 돌아가고, 잃는 건 몇 초뿐이다. 뒤로 갈수록 틈이 넓어지고 발판 타이밍이 짧아진다. *(provisional)*

## Core loop
- 다음 섬을 보고 점프 경로를 읽는다
- 점프하고 착지하며 체크포인트를 밟는다
- 실패하면 즉시 재시작해 같은 점프에 다시 도전한다
- 깃발을 밟으면 다음 구간으로 넘어간다

## Goal & fail state
- 목표: 마지막 섬의 깃발에 닿기 *(provisional)*
- 실패: 낙하하거나 적·가시에 닿으면 마지막 체크포인트에서 즉시 재시작. 목숨과 게임 오버는 없다 *(provisional)*

## Features
- [x] 3~4개 구간을 잇는 섬 코스와 체크포인트, 마지막 깃발
- [x] 정확한 점프: 길게 눌러 높이 조절, 빠른 낙하, 코요테 타임과 점프 버퍼
- [x] 착지 스쿼시와 먼지, 점프·착지 효과음, 발밑 그림자
- [x] 진행 방향을 보여 주는 orbit 카메라
- [x] 적 2종: 왕복하는 순찰병, 밟으면 튀어 오르는 가시 덩어리
- [x] 움직이는 발판과 사라지는 발판
- [x] 클리어 시간과 재시작 횟수를 보여 주는 결과 화면
